# Product Requirements Document: 松博教育官网宣传内容重构（promo-content-update）

## 1. 背景与问题陈述

### 1.1 项目背景

松博教育现有官网（songboai.cn，Astro 7 + Tailwind CSS v4 纯静态站）的线上宣传内容与最新版公司宣传 PPT 存在系统性不一致。PPT 是公司当前对外宣传的唯一权威口径（**冲突一律以 PPT 为准**），官网需以 PPT 为基准完成品牌、联系方式、业务板块、成果数据的全面重构，并对不合规宣传用语进行合规化改写。

## 2. 业务目标与成功指标

### 2.1 业务目标

- 官网宣传口径与公司最新 PPT 完全一致，消除虚构/夸大内容带来的品牌与合规风险。
- 通过真实案例、特色产品（666 产品）与本地化服务（濮阳专区）增强说服力，提升咨询转化。
- 联系方式统一为真实电话/微信/地址，确保用户咨询可达。

| 指标 | 目标 |
| :--- | :--- |
| 电话咨询量（18135773531 拨打点击） | 上线后环比提升（以旧站 400 电话点击为基线） |
| 表单留资量（联系我们页咨询表单提交） | 上线后环比提升 |
| 品牌口径统一率 | 100%（全站无"松博网络/SONGBO NETWORK"残留） |
| 构建质量 | `npm run build` 零错误、零类型断裂 |
| 合规风险词 | 全站无"保录取""全额退费（无条件表述）"等违规承诺用语残留 |

## 5. 非功能需求（NFR）

### 5.1 架构与技术约束

- 架构不变：Astro 7 SSG 纯静态站，零运行时 JS 框架，不引入 React/Vue 等依赖。
- 样式：Tailwind CSS v4（`@tailwindcss/vite`），主题令牌仅在 `global.css` 的 `@theme` 中维护。
- 类型：TypeScript strict 模式；`ServiceItem` 等接口变更须类型自洽，`npm run build` 零错误。
- Node.js `>=22.12.0` 约束不变。

### 5.2 数据与布局约束

- 内容集中管理：所有文案以 `src/data/site.ts` 为 Single Source of Truth；新增微信字段后所有消费方从 brand 读取。
- `stats` 必须保持 4 项（匹配 `grid-cols-2 lg:grid-cols-4`）。
- `vision.values` 保持 3 项；`team` 保持 4 项；`subsidiaries` 保持 5 项。
- `services.category` 同类名称精确一致，防止课程中心分组拆分。
- 空数组渲染安全：任何数组（services/stats/案例等）为空时组件不得报错或渲染破损（保持现有 `.map()` 模式的安全语义）。

### 5.3 合规策略（决策4 全文生效）

- "保录取"等效果承诺 → 能力目标/服务流程描述。
- "考不上目标学校全额退费" → "签约保障，未达目标按协议退费"。
- "脑象测评·心理状态评估" → "学习状态分析"等中性表述。
- 提分案例统一附加"个案效果，因人而异"声明。
- 成果数据保留限定语（"已帮助超500名""平均提分30分"）。

### 5.4 性能与兼容性

- 新区块不得引入第三方 JS 库或外部字体/图床资源；图标使用内联 SVG。
